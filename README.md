# Behind the Jersey: pipeline (archived)

**This repository is archived.** Everything moved to **[Beyond-The-Jersey/data](https://github.com/Beyond-The-Jersey/data)**:

- **The data:** one JSON file per record, with a schema, checks on every pull request, and a published [release](https://github.com/Beyond-The-Jersey/data/releases) (JSON, CSV, zip).
- **How to contribute, by hand or with an agent:** [CONTRIBUTING.md](https://github.com/Beyond-The-Jersey/data/blob/main/CONTRIBUTING.md) and the agent brief [agents/research.md](https://github.com/Beyond-The-Jersey/data/blob/main/agents/research.md).
- **The rating method:** [METHOD.md](https://github.com/Beyond-The-Jersey/data/blob/main/METHOD.md).
- **Research targets:** [docs/coverage](https://github.com/Beyond-The-Jersey/data/tree/main/docs/coverage) and the [issues](https://github.com/Beyond-The-Jersey/data/issues).

Nothing here is used by the data or by [behind-the-jersey.org](https://behind-the-jersey.org):

- **The first version:** Wikipedia and Wikidata scrapers, A–F grades and per-team files. Its contact details were placeholders; don't reuse them.
- **`data_build/`:** a copy of the data repo's old builder, which that repo has replaced.

It stays readable here for its history.
